# Daten der „Staatlichen Musterschule“

Alle Daten sind **frei erfunden** und enthalten keine personenbezogenen Daten. Sie dienen als Grundlage für die Tools
in den Labs.

| Datei | Inhalt | Verwendet in |
|---|---|---|
| `vertretungsplan.csv` | Vertretungen, Entfälle und Raumänderungen für die Woche 9.–13.11.2026 | Lab 02, 04, 05, 07 |
| `raumbelegung.csv` | Wöchentliche Belegung einiger Fachräume | Lab 02 Ausbau |
| `termine.json` | Schultermine November/Dezember 2026 | Lab 01, 04 |
| `stundenplan.json` | Stundenpläne der Klassen 7a und 10a | Lab 04 (Ressourcen-Vorlage) |
| `hausordnung.md` | Auszug aus einer Hausordnung | Lab 04 (Resource) |
